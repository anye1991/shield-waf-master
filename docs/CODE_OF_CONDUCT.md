# 行为准则（Code of Conduct）

> 对应 OpenSSF 最佳实践准则 `code_of_conduct`。参与本项目（Issue、PR、讨论、线下）即表示同意遵守本准则。

## 我们的承诺

为营造开放、友好的环境，无论年龄、体型、身体或精神障碍、族裔、性别认同与表达、经验水平、国籍、外貌、种族、宗教或性取向如何，项目均致力于让每位参与者免受骚扰。

## 我们的标准

**鼓励的行为**：
- 使用友好、包容的语言
- 尊重不同观点与经验，耐心解答新人提问
- 对事不对人，基于证据讨论技术方案
- 善意指出他人失误，并接受自己被指正

**不可接受的行为**：
- 涉及性暗示的语言或图像、不受欢迎的性关注
- 攻击性 / 贬损性评论，人身或政治攻击
- 公开或私下骚扰
- 未经许可发布他人隐私信息（住址、邮箱等）
- 在专业技术场景中其他可合理认定为不当的行为

## 责任与执行

- **维护者**负责澄清标准、对不可接受行为采取回应措施（警告、临时禁言、永久移除），并对处理过程保密。
- **举报渠道**：私信维护者 [暗夜铭少](mailto:azgq@foxmail.com)，或通过 [GitHub Issue / Discussion](https://github.com/anye1991/shield-waf-master/issues) 私密举报。
- 维护者收到举报后 7 日内给出处理结果。

## 适用范围

本准则适用于项目空间（仓库、Issue、PR、站点）以及代表项目的公开场合。
