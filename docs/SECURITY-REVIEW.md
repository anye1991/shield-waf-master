> 对应 OpenSSF 准则 `security_review`（gold MUST）：**近 5 年内完成过安全评审，评审必须覆盖安全需求与安全边界**。本报告为**内部安全评审**（准则允许 internal or external）。

## 1. 评审范围与方法

- **范围**：明文层（`shield-waf.php`、`runtime.php`、`qps.php`、`control.php`、`console.php`、`screen.php`、`pages.php`、`dna.php`、`features.php`、`i18n.php`、`install.php`、`config.php`、`build.php`）+ 加密层接口契约（`core/`、`ai/`）+ 随附扩展（`ext/`）+ 部署方式（`.user.ini`）。
- **方法**：
  1. 以 `SECURITY.md` 威胁模型为底本，逐条核对信任边界两侧的输入处理；
  2. 人工代码审读明文层（含 `tools/static_check.php` 规则复跑）；
  3. 动态验证：执行 `tests/` 自包含套件（adversarial / ai_check / feature_matrix / i18n / honeypot / qps）与 `fp_regression.sh` 误报回归；
  4. 对照论文评测结论核对检出能力边界声明的一致性（不夸大）。

## 2. 安全需求逐条核对

| 安全需求（SECURITY.md §4） | 结论 | 证据 |
|---|---|---|
| 已知攻击形态默认拦截、误报可复核 | **满足**（边界内） | 证据证书随阻断输出；`tests/adversarial.php`、`fp_regression.sh` |
| 请求路径无模型调用、确定性执行 | **满足** | YSL-1 四级流水线无 LLM/网络调用；`ARCHITECTURE.md` §3 |
| 文件 DNA 防篡改可发现并隔离后门 | **满足** | `dna.php` 规则集（webshell/马特征）+ 独立守护 |
| 限流与熔断默认开启 | **满足** | `qps.php` 滑动窗口；`tests/qps_check.php` |
| 蜜罐默认停用、启用过四道闸 | **满足** | v6.5.0 改动；`tests/honeypot_check.php` |
| 不引入弱密码学默认值 | **满足** | 无 SHA-1/CBC 弱模式默认依赖；核心加密为代码保护（见 §5 残留） |

## 3. 发现与处置

### 已处置（本版本前修复）
1. **403 退化为 200**：旧版拦截判定在部分路径未生效 → 已修，回归覆盖（`tests/control_check.php` 端到端验证真实落盘状态变化）。
2. **控制台危险操作无二次确认** → 已加二次确认与一次性 key（安装时打印含一次性 key 的控制台 URL）。
3. **蜜罐默认开启风险** → v6.5.0 改默认停用 + 确认短语/有效期/审批留痕/到期回退四道闸。

### 本轮评审新增处置项（进入 ROADMAP）
4. **[中] 加密文件来源校验缺失**：站点无法自行校验 `core/`、`ai/`、`ext/` 的完整性 → 处置：发布时提供各文件 SHA-256 清单（`docs/` 或 Release 附带），纳入 2026 Q4 发布签名流程。
5. **[中] `ext/beast-8.1.so` 为预编译二进制**：供应链信任依赖作者构建环境 → 处置：构建脚本（`.build/`，私有）记录构建参数；长期目标为公开构建说明以满足 `build_reproducible` 相关论证（当前按 PHP 解释型 N/A 论证，扩展部分单独说明）。
6. **[低] `Support/Functions.php` 随机采样**：原先使用 `rand()`（非加密安全）→ 本轮已改为 `random_int()`（对应本次整改）。

## 4. 残留风险（明示，不夸大）

- **误报**：语法层无法取得参数 sink 与业务上下文，误报治理依赖 HTTP 层证据持续降低（与论文结论一致，不作零误报承诺）。
- **性能与多方言泛化**：以设计论证/单点读数为准，生产环境以用户实测为准（README「结论边界」已声明）。
- **单人维护**：双人复核与贡献者梯队未达标（`GOVERNANCE.md` §5、`ROADMAP.md`），为当前最大组织性风险。

## 5. 结论

v6.5.0 在声明的安全需求与信任边界内**满足设计目标**，未发现边界两侧的未校验输入路径；上述 §3-4/5/6 两项中风险处置项进入下一版本。本评审有效期至**下一次评审或 2031-11-10（5 年）**以先到者为准。
